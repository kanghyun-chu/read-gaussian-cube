# read-gaussian-cube

Collection of MATLAB functions used to read Gaussian cube file. Cube format files generated from the Gaussian DFT package contain volumetric data (ie. molecular orbitals, charge distribution etc.). This program allows you to read the files into MATLAB as a struct with the following fields:
- filename, title, subtitle
- axis_1, axis_2, axis_3
- resolution
- config
- **cubedat**
- misc

## Utilities 
- `readCube.m`: Read a Gaussian cube file and return a struct object as an outputs.

### The following codes are yet as they were.
- `sliceCubeZ.m`: Slice the cube data generated from `readCube.m` at a specific z value.
- `plotSlice2d.m`: Plot a 2d slice in the plane of (x,y) generated by `sliceCubeZ.m`. Can plot atom positions as well if specified.
- `readXYZ.m`: Get the xyz coordinates from xyz file.
